# UNIVELORIA — Curtain Homepage

Homepage concept built with React + Vite, CSS, Lucide icons and GSAP entrance animations.

## Run locally

```bash
npm install
npm run dev
```

Open the localhost URL printed by Vite.

## Notes
- The hero uses one clean room image as the section background to avoid rectangular image edges and embedded caption artifacts.
- UI elements (brand, headings, buttons, preview card, color swatches) are HTML/CSS, not baked into the background image.
- The AI 3D Studio is a UI prototype. Real room-image processing and 3D curtain manipulation need a separate AI/3D implementation.
